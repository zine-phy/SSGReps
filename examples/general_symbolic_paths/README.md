# General symbolic-path reports

These reports are generated by the database-backed `--kpath` interface. They
contain symbolic Bloch phases with numerical constant matrices, not fully
algebraic matrix entries. They require no cached exact family or GAP executable.

| Example | SSG | Path | Generic dimensions | Reports |
| --- | --- | --- | --- | --- |
| MR | 221.8.6.3 | `(1/2,1/2,t)`, `0<t<1/2` | 4, 4 | [Text](MR.txt), [HTML](MR.html), [JSON](MR.json) |
| K-H | 194.1.6.1.P | `(1/3,1/3,t)`, `0<t<1/2` | 1, 1, 2 | [Text](KH.txt), [HTML](KH.html), [JSON](KH.json) |

From the repository root:

```bash
python ssgreps.py --ssgNum 221.8.6.3 \
  --kpath "1/2" "1/2" "t" --interval 0 1/2 \
  --out both --rep 1 --ops 3 --optimize --seed 19 --compact-characters \
  --text MR.txt --html MR.html --fileType json --export MR.json

python ssgreps.py --ssgNum 194.1.6.1.P \
  --kpath "1/3" "1/3" "t" --interval 0 1/2 \
  --out both --rep 1 --ops 4 --seed 19 \
  --text KH.txt --html KH.html --fileType json --export KH.json
```

Representation labels depend on the computed basis/order and need not match
labels in the cached exact examples. Compare complete character vectors up to
label permutation. Compact display columns are grouped only when their
underlying values are equal; numerical residuals can leave visually identical
columns separate.

Only unitary characters are tabulated. Matrices for antiunitary operations, when
selected, denote the matrix part of `D*K`. Endpoint tables must be calculated
separately. The [path guide](../../docs/symbolic_paths.md) explains nonlinear
paths, exceptional-point conditions, checked evaluation, and the export schema.
